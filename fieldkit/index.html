Administration checklist
  1. Use WPA2-AES and a trusted management network.
  2. Keep passwords and private keys out of dashboard files.
  3. Establish a maintained, key-only, pinned SSH connection.
  4. Test a second session, reboot, and recovery.
  5. Only then disable unnecessary Telnet / FTP.
An installed SSH binary or listening port is not proof of secure authentication. Do not disable your only working administration path.
This affects only the host prototype, never SanDisk services.
